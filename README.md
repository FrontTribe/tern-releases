# Tern for Mac

Downloads and the update feed for Tern, a browser for Mac with an agent in every Space.

- **Download:** the `.dmg` on the [latest release](https://github.com/FrontTribe/tern-releases/releases/latest). Tern needs macOS 26.
- **Updates:** Tern checks `appcast.xml` on the latest release once a day and installs only builds signed with Tern's key.

Every build is signed with a Developer ID and notarized by Apple. The source code is private.
